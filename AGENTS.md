# Agent instructions (Grok Build, Cursor, cloud agents, and others)

**Sync before you start.** Run `git fetch origin && git status -sb`. If you're behind, run `git pull --ff-only origin main`. If local uncommitted changes conflict, stop and ask. Commit and push promptly when done. Cloud agents work on a branch/PR from the latest `main`.

Full rules, the ship path and active claims are in **[LLM_COORDINATION.md](./LLM_COORDINATION.md)**. Read it before non-trivial edits.
